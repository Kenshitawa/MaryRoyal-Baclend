# Parent guide

Sign in with the Parent account credentials from README and change the temporary password when prompted. The portal shows only children explicitly linked by the Director. If a child is missing, contact the school office; the portal cannot add or switch to an unlinked learner.

Use the child tabs to switch between linked children. The portal shows attendance, released subject marks, term fee balances and links to print/save receipts as PDF. Results appear only after school release. Full report cards, timetable, homework, announcements and messaging remain on the roadmap. Do not use a real family account in this prototype.
