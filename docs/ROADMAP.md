# Roadmap

The current build is a local prototype with login/account administration, a learner register, a scoped CBC mark workflow and a basic audited invoice/payment/receipt workflow. It is not the complete Mary Royal SMS from the brief and is not ready for real learner or finance data.

- Expand data models for full learner details, school years/terms, formal classes/streams/subjects and multi-role grants. Guardian links and demo family links exist.
- Finish Director accounts with printable credential slips, bulk CSV/Excel import validation, role grants and session revocation. Basic create, suspend/reactivate, reset and unlock work.
- Complete server-side authorization and row scoping for every route/action. Unit tests exhaustively cover the centralized permission matrix, and browser tests attempt major writes by each seeded non-Director role; they do not exercise every route/action/IDOR. Add durable rate limits, idle timeout, session revocation, CSP nonce policy and privacy/access workflows.
- Finish academic setup and attendance, including teacher assignments managed by the Director/Head Teacher, class registers, edit approval and attendance follow-up.
- Complete CBC configuration, deadlines/reopen approval, strand/competency catalog, bulk marks entry/import, immutable history review and term report cards/PDF. Family accounts currently see released subject marks, not full report cards.
- Build fee structures/templates, adjustments, Director-approved waivers, expenses, arrears statements and finance PDF/Excel reports. Current invoice lines, payment methods, unique M-Pesa code, carry-forward credit, sequential receipt, history, void reason, print receipt and a versioned Accountant-managed payroll sheet exist; receipt void is blocked after credit use pending reconciliation.
- Build clash-checked timetable, duty/cover, discipline, notifications/announcements, moderated messages, lesson plans, homework/resources and events.
- Expand the Parent and Learner portals (secure guardian links and basic linked views exist); build role-specific analytics beyond the Director’s schoolwide enrollment, attendance, fee collection/balance by class and monthly payroll overview; add search, comprehensive PDF/Excel exports and real notifications. A Director learner-register CSV is implemented.
- Add offline PWA caching, accessibility and performance reviews, backup/restore verification, privacy data requests, finished role guides and operational hardening. The public privacy notice is informational and is not a data request workflow. docs/DEPLOYMENT_GUIDE.md is a later planning guide only.
